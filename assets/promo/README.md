# 知序案例宣传片

《return_rp · 从一句话，到可编辑原型》以原创「知序」考研复习 App 为案例，使用 huashu-motion 制作。成片为 40 秒、1920×1080、60 fps，含原创配乐与音效，无口播。

画面依据案例规格重建，用于说明需求到原生可编辑 `.rp` 的流程；不是软件录屏，视频转场也不是 Axure 自带动画。片中的 12 页、840 个元件、74 个交互事件仅指该案例，不代表通用生成速度或质量保证。
